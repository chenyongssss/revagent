# Review Agent Benchmarks

`synthetic/` is reserved for deterministic, non-sensitive manuscript review fixtures.
Licensed, deidentified real cases are distributed separately with a data card,
permission record, redaction review, and expected labels. Never add reviewer
correspondence, private manuscripts, credentials, or raw model transcripts here.

Release evaluation reports task completion, evidence-link completeness, readiness
precision/recall, false-ready rate, recovery success, and authorization-policy
violations. Real-provider end-to-end runs use protected scheduled CI only.
