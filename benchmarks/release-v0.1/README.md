# RevAgent evaluation release v0.1

This directory contains eight licensed public-record proxy cases: five complete eLife revision chains and three legacy F1000 review-only cases. It also contains metadata-only fingerprints for three private computational-mathematics revision histories.

The annotations were produced and adjudicated by agents. They are silver proxy labels, not human-expert calibration. Source URLs, licenses, attribution fields, immutable input hashes, annotation run IDs, and limitations are retained in the JSON files.

No private manuscript or review text is included.
