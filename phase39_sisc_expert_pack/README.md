# Phase 39 Expert Pack

This package contains three privacy-preserving, frozen shadow-mode artifacts:

- `planner_spec.json`: a high-risk proof planning contract;
- `actor_bundle.json`: hash-addressed snapshots only;
- `reviewer_report.json`: an `escalate` verdict, not a correctness finding.

## What to assess

Using the original case files privately and locally, each independent expert should score the
following dimensions from 0 to 1: `plan_lane_accuracy`, `high_risk_recall`,
`defect_detection_recall`, `false_pass_rate`, and `claim_provenance_completeness`.

Do not copy manuscript or response text, names, affiliations, manuscript identifiers, or contact
details into this package or the score record. Submit scores under a non-identifying pseudonym.

The reviewer verdict correctly remains unresolved: mathematical correctness and citation
applicability require a qualified human review.
